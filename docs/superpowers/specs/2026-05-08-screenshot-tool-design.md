# 截图工具设计文档

**日期**: 2026-05-08
**状态**: 已批准
**作者**: Sisyphus

---

## 1. 概述

一款轻量级跨平台桌面截图工具，类似微信截图功能。用户通过热键触发截图，框选区域后可进行多种标注操作，最终结果复制到剪切板。

### 核心目标
- **轻量**: 体积小（Tauri 方案，~5-10MB）
- **跨平台**: Windows / Mac 支持
- **快速**: 热键触发，流畅体验
- **功能完整**: 支持矩形、椭圆、箭头、线条、涂鸦、马赛克、文本、图片插入等标注

---

## 2. 技术栈

| 层 | 技术 | 职责 |
|----|------|------|
| 后端 | Rust + Tauri | 热键监听、屏幕截图、剪切板写入、系统托盘、窗口管理 |
| 前端 | Vue 3 + TypeScript | 框选模块、标注模块、工具栏、画布渲染 |
| 画布 | HTML5 Canvas | 截图底图 + 标注层叠加 |

| 模块 | 职责 | 语言 |

## 4. 功能设计

### 4.1 热键

| 平台 | 热键 |
|------|------|
| Windows | `Ctrl + Shift + A` |
| Mac | `⌘ + Shift + A` |

自动适配平台，无需用户配置。

### 4.2 系统托盘

```
系统托盘区域（屏幕右下角）
   ↓
   📷 (小图标)  ← 右键点击
   ↓
┌─────────────────────┐
│ 📸 截图             │  ← 点击直接触发截图
│ ─────────────────── │
│ 🚪 退出             │  ← 关闭程序
└─────────────────────┘
```

### 4.3 交互流程

```
步骤 1：按热键 (Ctrl/⌘ + Shift + A)
         ↓
步骤 2：屏幕变暗，进入框选模式
         ↓
步骤 3：鼠标拖拽画矩形选区
        - 选区内保持明亮，选区外变暗
        - 显示选区尺寸提示（如 "800 × 600"）
         ↓
步骤 4：松开鼠标，进入标注模式
        - 顶部出现工具栏
        - 选区位置不变，可以在上面画标注
         ↓
步骤 5：使用标注工具（可选）
         ↓
步骤 6：点击"完成"
        - 最终图像复制到剪切板
        - 窗口关闭
        - 可以直接 Ctrl+V 粘贴
```

### 4.4 快捷操作

| 操作 | 效果 |
|------|------|
| 框选后直接按 `Enter` 或 `双击选区` | 跳过标注，直接复制到剪切板 |
| 框选后按 `Esc` 或 `鼠标右键` | 取消截图，关闭窗口 |
| 标注中按 `Esc` 或 `鼠标右键` | 取消标注，关闭窗口 |
| `Ctrl+Z` / `⌘+Z` | 撤销上一步标注 |
| `Ctrl+Shift+Z` / `⌘+Shift+Z` | 重做 |

## 5. 标注工具设计

### 5.1 工具清单

| 工具 | 图标 | 颜色选择 | 线宽/大小选择 | 说明 |
|------|------|----------|---------------|------|
| 矩形 | □ | HSL 模块 | 1px ~ 10px 滑块 | 边框颜色 |
| 椭圆 | ○ | HSL 模块 | 1px ~ 10px 滑块 | 边框颜色 |
| 箭头 | → | HSL 模块 | 1px ~ 10px 滑块 | 箭头颜色 |
| 线条 | ╱ | HSL 模块 | 1px ~ 10px 滑块 | 线条颜色 |
| 涂鸦 | ✏ | HSL 模块 | 1px ~ 10px 滑块 | 画笔颜色和粗细 |
| 马赛克 | ▦ | ❌ | 块大小滑块 | 只需调整模糊块大小 |
| 插入图片 | 🖼 | ❌ | ❌ | 按选区缩放 |
| 文本 | T | HSL 模块 | 字号档位 | 文本颜色和大小 |


### 5.3 颜色选择器（HSL 模块）

**设计为独立模块**，便于后续替换为固定色板。

```
┌─────────────────────────────────────┐
│  H: [━━━━━━━━━━━━━━━━━] 0°         │  ← 色相滑块 0~360
│  S: [━━━━━━━━━━━━━━━━━] 100%       │  ← 饱和度滑块 0~100%
│  L: [━━━━━━━━━━━━━━━━━] 50%        │  ← 亮度滑块 0~100%
│                                     │
│  预览: [■]  当前颜色                 │
└─────────────────────────────────────┘
```

**模块接口**：
- 输入：用户交互
- 输出：HSL 颜色值 `{ h: number, s: number, l: number }`
- 可替换为：固定色板模块（如 8 种常用颜色）

### 5.4 线宽选择器

```
线宽: [━━●━━━━━━━━] 2px

范围: 1px ~ 10px
```

### 5.5 文本工具

**字号档位**: 12 / 16 / 20 / 24 / 32 / 48 / 72 px

**交互方式**：
1. 选择文本工具
2. 在截图区域点击
3. 出现输入框
4. 输入完成 → 点击其他地方或按 Enter → 文本渲染到画布

### 5.6 马赛克工具

**马赛克块大小滑块**：
- 范围：5px ~ 30px（可调）
- 效果：值越大，模糊块越大

### 5.7 插入图片

**交互方式**：
1. 选择插入图片工具
2. 弹出文件选择对话框
3. 用户选择图片
4. 图片按截选区域等比缩放，不超出截选区域
5. 用户可以拖拽放置位置

## 6. 独立模块

### 6.1 窗口拟合模块

**功能**：鼠标悬停在应用窗口边缘时，截选边缘自动拟合到该窗口边缘。

**设计为独立模块**，如果效果不佳可以整体移除。

**实现思路**：
- Rust 后端获取鼠标位置下的窗口句柄
- 获取窗口边界坐标
- 前端在框选时，如果鼠标接近窗口边界（阈值内），自动吸附

**模块接口**：
- 输入：鼠标坐标 `{ x: number, y: number }`
- 输出：拟合后的坐标 `{ x: number, y: number }` + 是否拟合标志

### 6.2 HSL 颜色选择模块

**功能**：提供 HSL 颜色选择界面。

**设计为独立模块**，后续可替换为固定色板。

**模块接口**：
- 输出：`{ h: number, s: number, l: number }`

## 7. 数据流

```
热键触发
   ↓
Rust: 捕获全屏截图 → 通过 IPC 发送 base64 图像数据
   ↓
Vue: 接收图像 → 加载到 Canvas 作为底图
   ↓
Vue: 框选模式 → 用户拖拽选区 → 记录选区坐标
   ↓
Vue: 标注模式 → 用户绘制标注 → 标注记录在内存中
   ↓
Vue: 点击完成 → 合并底图 + 标注 → 导出为 PNG Blob
   ↓
Rust: 接收 PNG Blob → 写入系统剪切板
   ↓
Vue: 关闭窗口
```

## 9. 非功能需求

- **性能**: 截图捕获 < 100ms，标注响应 < 16ms（60fps）
- **体积**: 最终打包 < 15MB
- **兼容性**: Windows 10+, macOS 10.15+
- **内存**: 空闲 < 50MB，截图时 < 200MB
